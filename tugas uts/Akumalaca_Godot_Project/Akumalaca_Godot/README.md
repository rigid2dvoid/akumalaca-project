# JACK O' WAY: AKUMALACA

Prototype game 2D side-scroller/brawler berbasis Godot 4, dibuat dari aset yang disertakan dalam tugas.

## Menjalankan
1. Ekstrak folder `Akumalaca_Godot`.
2. Buka Godot 4.2 atau lebih baru.
3. Pilih **Import** lalu arahkan ke `project.godot` di folder ini.
4. Tekan **F6** (atau **F5** untuk menjalankan project utama).

Tidak memerlukan plugin, asset store, atau internet.

## Kontrol
- `A` / `D` atau `←` / `→`: bergerak
- `SPACE` / `W` / `↑`: lompat
- `J` / `K`: serangan lengan cybernetic
- `R`: ulangi setelah menang/kalah

## Isi prototype
- Planet Akumalaca sebagai arena side-scroller.
- Jack O' Way sebagai karakter pemain.
- Monoseeds sebagai heavy-enforcer dengan AI mendekat dan menyerang.
- HP pemain dan musuh, serangan jarak dekat, kondisi menang/kalah, dan restart.

Catatan: aset karakter yang tersedia berupa ilustrasi pose depan/T-pose, bukan sprite sheet animasi side-view. Prototype menggunakan ilustrasi tersebut sebagai sprite statis yang dibalik saat menghadap kiri; gerak dan pertarungan sudah dapat dimainkan.
